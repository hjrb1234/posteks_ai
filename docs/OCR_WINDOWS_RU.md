# Tesseract и частичная обработка PDF на Windows

Если раньше весь PDF получал ошибку из-за одной страницы, требующей OCR, после обновления текстовые страницы сохраняются и участвуют в поиске. Оригинал и визуальный просмотр страниц остаются доступны. Статус с предупреждением означает, что часть изображений не распознана; это не полная индексация всех сведений руководства.

## Диагностика

Остановите сервер, откройте PowerShell в папке `posteks_ai` и выполните:

```powershell
.\.venv\Scripts\python.exe -m scripts.install_ocr --check
```

Команда показывает наличие исполняемой программы, папку языков и наличие `rus`/`eng`; база данных не открывается и не меняется. Отдельно различаются: программа не найдена, неверный `TESSERACT_CMD`, отсутствующая папка данных, недоступные языки и зависший процесс.

## Исправление

1. Если Tesseract не установлен, установите Tesseract OCR 5 из доверенного источника. Не путайте бинарную программу с Python-пакетом `pytesseract`: они нужны оба. `pytesseract` устанавливает `install.bat`, сама программа ставится отдельно.
2. Установка вне `PATH` поддерживается: проверяются `TESSERACT_CMD` и стандартные папки `Program Files/Tesseract-OCR`, `Program Files (x86)/Tesseract-OCR`, локальная папка программ пользователя. Если программа находится в другом месте, укажите путь в локальном `.env`:

```dotenv
TESSERACT_CMD=C:/Program Files/Tesseract-OCR/tesseract.exe
TESSDATA_PREFIX=./storage/tessdata
```

3. Подготовьте языки из официального закреплённого набора с проверкой SHA-256:

```powershell
.\.venv\Scripts\python.exe -m scripts.install_ocr
.\.venv\Scripts\python.exe -m scripts.install_ocr --check
```

`TESSDATA_PREFIX` — папка, содержащая `rus.traineddata` и `eng.traineddata`, не путь к одному файлу. Относительные пути считаются от папки проекта. При своём `SERVICE_STORAGE_ROOT` или `STORAGE_DIR` проверьте фактическую папку в диагностике. Если `TESSDATA_PREFIX` явно указан, команда установки использует именно его.

4. Запустите `start.bat`. В базе знаний у ошибочного или частично обработанного документа выберите **«Обработать заново»**. После успешного OCR предупреждение исчезнет. Повторная установка приложения сама по себе не ставит все старые ошибки в очередь.

## Что происходит при ограничениях

- Один сбой OCR не удаляет остальные текстовые страницы PDF. В предупреждениях перечислены номера проблемных страниц.
- Полный скан без доступного текста остаётся ошибкой; реальное количество страниц и причина сохраняются. Помощник не получает выдуманный текст скана.
- Если переиндексация уже обработанного оригинала не удалась, прежний полезный индекс сохраняется с предупреждением. Он не помечается как успешная новая обработка.
- На OCR одной страницы действует предел 20 секунд, за одну обработку — 16 страниц OCR. Большой полный скан разделите на части или сохраните PDF с текстовым слоем. Эти пределы не ограничивают чтение обычных текстовых страниц PDF.
- Схема или иллюстрация может не содержать текста. Визуальный просмотр остаётся источником для инженера; отсутствие распознанной надписи не означает, что чертёж понят автоматически.

Изменение проверено в облаке на смешанных PDF и тестах ошибок OCR. Фактический запуск Windows/Tesseract на вашем компьютере нужно проверить указанной диагностикой.
