# Проверка ошибки модели и локальная самопроверка — 12 ноября 2026

Сайт на скриншоте запустился: HTTP 200 и `Application startup complete` подтверждают работу сервера. Они не подтверждают успешный ответ OpenAI. Точную причину отказа на вашем компьютере по прежнему общему сообщению установить нельзя. Ваш ключ и доступ к Яндексу в облачной копии отсутствуют.

## Найдено в коде и исправлено

| До | Теперь | Подтверждение |
|---|---|---|
| Разные ошибки обработки ответа попадали в общее «запрос не выполнен» | Отдельные коды для сети, доступа, неполного ответа, JSON, схемы и неподтверждённой цитаты; в журнале безопасные этап и ID | Воспроизводимые ответы SDK и ошибки протокола в автоматических тестах |
| Перед генерацией обязательно читались метаданные модели | Генерация не требует отдельного права на чтение метаданных | Тест: чтение метаданных отклоняется, корректная генерация принимается без этого вызова |
| Проверка подключения просила короткое неструктурированное `OK` | Проверяется формат рабочего чата, завершённость и принятие результата приложением | Тесты корректного/повреждённого/незавершённого результата |
| Статус `incomplete` мог выглядеть как обычная ошибка JSON | Показывается `response_output_limit` или другая причина незавершённости; расход и ID сохраняются | Тесты SDK с непустым, но незавершённым ответом |
| Лимит вывода был зафиксирован в коде на 1800 токенах | `MAX_AI_OUTPUT_TOKENS` настраивается в `.env`, по умолчанию 4096, с проверкой границ | Тест конфигурации; увеличение лимита не объявляется доказанным исправлением вашей конкретной ошибки |
| Не было одного запуска для проверки установленной копии | `check.bat` создаёт HTML и ограниченный отчёт для поддержки, использует ваш локальный ключ | Полный маршрут проверен через реальные API приложения; транспорт OpenAI в автоматических тестах заменён SDK-заглушкой |

Ошибки API не подменяются советом по ремонту. Исторический импорт не запускает новые действия. Дизайн сохранён; в настройках только уточнена подпись моделей, которые ещё не вызывались: «не проверялась».

## Что проверено здесь

- Общий набор: **382 теста прошли**. Дополнительно после уточнения проверки памяти повторно проверен изменённый модуль самопроверки и отчёта.
- Сборка frontend успешна. Настоящий браузер прошёл пять групп проверок: отправка пяти реплик, сохранение после перезагрузки, изоляция чужого диалога, честная ошибка в Playground и инертный повторный импорт архива. Ошибок JavaScript нет. Настоящая модель в этом проходе не вызывалась.
- Новый запуск проверен на настоящем локальном руководстве: файл принят, обработан и найден через API. Проверены закрытый оригинал, ожидаемые отказы повреждённого PDF и пустого сообщения, отсутствие действий из архива и отсутствие дубля.
- Отдельно пройдена вся ветка из 15 генераций с SDK-заглушкой: пять прямых реплик, пять через приложение, три технические реплики с памятью, ответ с источником и описание остановки привода. Это проверка программы, а не качества настоящей модели.
- Отсутствующий ключ не засчитывается как успешное подключение. Настоящие вызовы OpenAI и Яндекса в облачной проверке: **0**.
- Рабочая SQLite до и после запуска совпала побайтно; исходные приватные файлы сохранены. Пробные записи создаются в одноразовой базе.

На Windows нужно проверить запуск BAT/PowerShell. На вашей настоящей модели остаются неподтверждёнными связность и инженерная правильность ответов. Реальная доступность годовой почты, всех вложений и многолетней группы MAX здесь не проверена. Два образца IMAP не означают импорт года.

## Как повторить

Обновите программные файлы, сохранив `.env`, рабочую БД и хранилище, затем дважды щёлкните **`check.bat`**. Откроется новый отчёт. Для дальнейшего исправления пришлите только **`support_report.json`** из той же папки. Ключи, почту, БД и `PRIVATE_details.json` присылать не нужно.

Запуск делает до 20 генераций OpenAI и читает до двух образцов IMAP. Исходящие письма не отправляются. Подробная инструкция, ограничения, MAX и накопление подтверждённых знаний: [SELF_CHECK_RU.md](SELF_CHECK_RU.md).
