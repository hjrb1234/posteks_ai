# Дизайн POSTEKS AI

Это скриншоты действующих React-страниц из автономного TEST-просмотра. Все записи вымышлены; оригинальных документов компании и реестра здесь нет.

Для взаимодействия распакуйте переданный локальный Windows ZIP и запустите `install.bat`, затем `start.bat` и `open-app.bat`. Подробности — в [Windows-инструкции](../WINDOWS.md). Прежний автономный TEST HTML в новую поставку не включён. Галерея ниже сохраняет снимки предыдущей версии; актуальные сценарии проверяются в работающем приложении.
