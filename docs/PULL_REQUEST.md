В репозитории отсутствовал сервисный проект. Ветка добавляет локальную основу POSTEKS AI: FastAPI/SQLAlchemy/Alembic, React/TypeScript, авторизацию сотрудников, изолированный чат, библиотеку документов с поиском и страницами-источниками, обращения/поручения, тестовый импорт писем, черновики, согласование и реестр.

Для проверки без установки подготовлен интерактивный HTML из тех же компонентов React. Он явно обозначен TEST, использует только искусственные записи и не подключается к почте/OpenAI. Страница подготовлена для GitHub Pages; включение Pages требует отдельного разрешения владельца. Работа Python-backend требует запуска приложения.

- Дизайн и скриншоты: https://github.com/hjrb1234/posteks_mvp/blob/codex/posteks-ai/docs/design/README.md
- Самодостаточный интерактивный файл: downloads/posteks-preview.html (также внутри ZIP). Веб-адрес Pages пока не активирован: API вернул403 Resource not accessible by integration.
- Windows-пакет: https://github.com/hjrb1234/posteks_mvp/raw/refs/heads/codex/posteks-ai/downloads/posteks_ai_windows.zip
- Запуск Windows: docs/WINDOWS.md. В ZIP есть готовый frontend; создаются новая БД и личный администратор без общего пароля.
- Включены схема БД без строк, миграции и безопасный .env.example. Заполненная БД, .env, исходные PDF/Excel, резервные копии и внутренние документы исключены из Git и ZIP; локальные материалы сохранены.

Проверено:38 тестов backend/публикации, production TypeScript/Vite build, настоящий backend через Chromium в временной БД,9 проверок автономного просмотра, мобильная компоновка, отсутствие внешних запросов просмотра, состав/CRC/SHA-256 архива. Подробности: docs/RELEASE_VALIDATION.md.

Windows runtime, живые OpenAI/IMAP и перенос прежней большой базы ещё не проверены. SMTP остаётся заблокированным. Голос, видеоанализ, автоматическая почта и семантический поиск остаются дальнейшими этапами.
