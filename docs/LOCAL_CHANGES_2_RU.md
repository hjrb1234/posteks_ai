## Данные и конфиденциальность

- Рабочие документы, база и `.env` не подменяются выпуском программы. Резервные копии сохраняются отдельно от общего ZIP.
- Программный архив содержит код, собранный frontend и инструкции. Из него исключены `.env`, SQLite, storage, реальные письма, PDF/Excel компании и автономный HTML прежней версии. Почтовый fixture в тестах вымышленный.
- Отдельный частный комплект возвращает владельцу прикреплённые PDF/реестр для однократного локального импорта. Он не предназначен для GitHub или публичного размещения, не содержит ключей и не заменяет прежнюю БД.
- Документы сначала внутренние. Для клиентской поддержки администратор отдельно разрешает подходящий документ. Сырая история не публикуется и не становится проверенным советом после импорта.
- «Почта настроена» означает наличие полей. Соединение и импорт проверяются отдельными операциями. SMTP заблокирован во всех режимах.
- Накопление знаний означает поиск по документации и подтверждённым решениям. Веса модели автоматически не меняются.

## Что требует вашей проверки

- **Windows:** облачные проверки используют Linux. Фактическое выполнение BAT/PowerShell на Windows не объявляется проверенным.
- **Яндекс и OpenAI:** настоящие учётные данные отсутствуют. Автотесты не доказывают соединение с вашим ящиком и качество ответов конкретной модели. Выполните `TESTING_GUIDE_RU.md` локально.
- **Прежняя система:** большие `posteks.db`, `alembic.zip` и повторный `frontend.zip` превышают лимит передачи 32 МиБ. Их содержимое не прочитано и не считается объединённым с веб-версией. Последний список файлов не содержит нового доступного файла `.db`.
- **MAX:** импортируется документированный текстовый файл. Автоматического доступа к личному аккаунту нет; официальные сведения — в `MAX_IMPORT_RU.md`.
- **DOC/XLS:** адаптер LibreOffice подготовлен, но сам конвертер не установлен в облаке. Бинарное преобразование проверяется отдельно.
- **Поиск:** локальный индекс лексический. Сложные таблицы нескольких модификаций и применимость деталей требуют инженерной проверки. Настройка embeddings не означает завершённый семантический поиск.
- **Следующие этапы:** видеоанализ, нативные мобильные приложения и production-размещение сюда не входят. Доля 80% самостоятельных решений оценивается на реальных обращениях и не гарантируется числом экранов или тестов.

## Как проверить у себя

Следуйте `TESTING_GUIDE_RU.md`: запуск → диагностика путей → PDF → поиск/источники → длинный диалог → специалист → письмо/история → повторный старт → backup и обновление. Для замечания укажите действие, ожидаемый и фактический результат, время и request ID; пароль, токен и приватную переписку не отправляйте.
