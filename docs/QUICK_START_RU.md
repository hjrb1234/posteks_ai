# Как обновить и проверить POSTEKS на Windows

1. Остановите POSTEKS сочетанием Ctrl+C в окне `start.bat`. Сохраните резервную копию рабочей базы, хранилища и `.env` в закрытой папке. [Инструкция по резервному копированию и откату](../TESTING_GUIDE_RU.md#9-обновление-без-потери-данных-и-откат)
2. Распакуйте ZIP отдельно. Скопируйте содержимое папки `posteks_ai` поверх программных файлов в вашей действующей установке. Сохраните прежние `.env`, `storage`, `.venv`, резервные копии и настроенные внешние каталоги.
3. Запустите `install.bat`. После успешной установки запустите `start.bat`.
4. Дважды щёлкните `check.bat`. Проверка прочитает состояние локальных файлов, индекса и истории почты. Пробные операции выполняются в отдельной временной базе. Отчёт откроется после завершения проверки.

## Проверка OpenAI

Команда для PowerShell из папки программы проверяет ответы настроенной модели и ссылки на источники.

```powershell
.\check.bat -Live
```

Этот режим использует ключ из локальных настроек и может сделать до 20 запросов к OpenAI на тестовых данных. Запросы расходуют квоту. Проверка почты в обоих режимах читает только сведения из местной базы. Доступ к Яндексу и полнота истории требуют отдельной проверки.

## Поиск руководств

Поиск включён по умолчанию. Если разрешённые локальные источники не содержат совпадения по модели и теме или коду ошибки, чат может искать руководство через OpenAI. Поисковый запрос содержит модель, код ошибки и вид технического вопроса. Бот показывает ссылку и выдержку, только если текст удалось прочитать на разрешённом официальном сайте. В существующем `.env` можно задать список доменов изготовителей через запятую в `POSTEKS_WEB_SEARCH_DOMAINS` (по умолчанию `veichi.com,posteks.ru`) или отключить поиск через `POSTEKS_WEB_SEARCH_ENABLED=false`. После правки перезапустите `start.bat`.

## Проверка видео

Если `check.bat` показывает предупреждение о средствах обработки видео, установите [FFmpeg для Windows](https://ffmpeg.org/download.html#build-windows) с программами `ffmpeg.exe` и `ffprobe.exe`. Можно установить через PowerShell командой `winget install --id Gyan.FFmpeg --exact`. Перезапустите `start.bat` и повторите загрузку. Путь к каждой программе можно указать в локальном `.env` через `FFMPEG_PATH` и `FFPROBE_PATH`. После успешной обработки модель видит выборочные кадры.

## Какой отчёт прислать

Прикрепите к чату **только `support_report.json` из нового запуска**. Точный относительный путь появится в окне проверки. Файл также доступен по ссылке в открывшемся `REPORT.html`.

Храните `PRIVATE_details.json`, `.env`, рабочую базу и каталог `storage` у себя. Если новый отчёт не появился, пришлите текст ошибки из окна проверки без ключей, паролей и личных путей.
