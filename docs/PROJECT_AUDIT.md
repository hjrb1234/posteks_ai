# Состав проекта и границы переноса

Проверены исходники frontend React/TypeScript, backend FastAPI, модели SQLAlchemy, миграции Alembic, конфигурационные шаблоны, Windows/Linux-скрипты и тесты. Это самостоятельная локальная основа POSTEKS AI; ранее упомянутые исходные app.py/user.py/admin_panel.py/docqa_manual.py и оригинальная большая posteks.db не были доступны для аудита и ещё не объединены с ней.

| Компонент | В GitHub/безопасном архиве | Состояние |
| --- | --- | --- |
| Frontend | frontend/src, public, package-lock.json | Чат и закрытые рабочие разделы; реальный API |
| Backend | server/ | FastAPI, авторизация, права, знания, обращения, безопасная почта |
| База | database/schema.sql, migrations/, server/models.py | Схема без данных; новая SQLite создаётся при запуске |
| Заполненная локальная БД | Исключена, сохранена в рабочей среде | Не публикуется и не заменяется |
| Исходные документы и Excel | Исключены, сохранены в рабочей среде | Загружать только в локальный/защищённый сервер |
| Конфигурация | .env.example | Секретные значения пусты |
| .env, сессии, резервные копии | Исключены | Существующие файлы сохранены |
| Windows-пакет | downloads/posteks_ai_windows.zip | Код, готовый frontend, схемы, инструкции; без закрытых данных |
| Просмотр дизайна | downloads/posteks-preview.html | Те же React-страницы, самостоятельный TEST-режим с вымышленными данными |
| Документация | README, docs/WINDOWS.md, DEPLOYMENT.md, PLAN.md | Запуск, ограничения, резервирование и дальнейшая работа |

Исходные вложения, прежний частный архив, заполненная база и локальные отчёты с данными не удалены. Они исключены через .gitignore и проверку состава публикации. Отдельная ветка позволяет проверить код перед переносом в main.

Автономный просмотр не заменяет backend и не проверяет реальные интеграции. Для полноценной работы используется Python-сервер. Отправка почты в текущей реализации отключена во всех режимах.
