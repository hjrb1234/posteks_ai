# Просмотр текущей локальной версии

Текущая поставка проверяется через настоящий backend: распакуйте программный ZIP, при необходимости добавьте отдельный частный комплект документов, выполните `install.bat`, затем `start.bat` и `open-app.bat`. См. [Windows](WINDOWS.md) и [руководство проверки](../TESTING_GUIDE_RU.md). Новые изменения не публикуются в GitHub; публичного рабочего сайта для этой версии нет.

Снимки экрана иллюстрируют дизайн. Для проверки форм, документов, переписки и сохранения состояния используйте запущенную программу. Старые автономные HTML-файлы исключены из нового программного ZIP.

---

Ниже сохранены материалы прежней поставки. Инструкции Pages относятся к ней; для текущего локального тестирования публикация не требуется.

# Архивная инструкция просмотра версии 1

## Уже доступно

- [Галерея реальных React-страниц](design/README.md): чат, обработка писем, база знаний и мобильный экран.
- [Готовый ZIP](../downloads/posteks_ai_windows.zip): нажмите Download raw file, распакуйте, откройте `downloads/posteks-preview.html` двойным щелчком. Не открывайте raw HTML как веб-ссылку GitHub: GitHub отдаёт HTML как текст; нужен скачанный файл либо настроенный Pages.
- Для настоящего backend выполните установку и запуск по [Windows-инструкции](WINDOWS.md). В Codespaces предусмотрена конфигурация с приватным портом8080.

Самостоятельный HTML использует те же компоненты React, но отдельный обозначенный TEST-транспорт. Меню, темы, формы, черновики, обращения и поручения можно проверить без установки Python. Данные вымышлены и сбрасываются при перезагрузке; документы компании/ключи отсутствуют. Это просмотр интерфейса, а не размещённый Python-сервер.

## Онлайн-просмотр GitHub Pages — последнее действие владельца

Страница подготовлена: `docs/index.html` и `docs/.nojekyll`. Попытка включить Pages через доступную GitHub-интеграцию получила403 `Resource not accessible by integration`; права на Git push/PR не дают этой интеграции права на настройку Pages. Это не исправляется изменением исходников и не требует API-ключа OpenAI.

1. Откройте https://github.com/hjrb1234/posteks_mvp/settings/pages под владельцем репозитория.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **codex/posteks-ai**, папку **/docs**, нажмите **Save**.
4. Дождитесь успешного Pages deployment. GitHub покажет адрес сайта; ожидаемый адрес — `https://hjrb1234.github.io/posteks_mvp/`. До активации этот адрес не является проверенной рабочей ссылкой.

После слияния PR и перед удалением feature-ветки переключите источник Pages на `main /docs`. Страница остаётся TEST-просмотром и не публикует конфиденциальную базу. Для реальных данных и интеграций необходим отдельный защищённый backend.
