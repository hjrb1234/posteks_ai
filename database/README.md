# База данных

В репозиторий включены **схема без строк** (`schema.sql`), модели SQLAlchemy и миграции Alembic в `migrations/`. Рабочая база, история обращений, сотрудники и реестр не публикуются.

При установке создаётся новая пустая SQLite `storage/posteks_ai.db`:

```powershell
.\.venv\Scripts\python.exe -m scripts.manage init-db
```

Паролей и пользователей по умолчанию нет. При первом `start.bat` администратор задаёт собственный пароль. Документы загружаются после входа через «База знаний» и остаются внутренними до отдельной публикации.

`schema.sql` нужен для просмотра структуры, а штатная установка/обновление используют Alembic. Не запускайте SQL поверх существующей рабочей БД. Исходная `posteks.db` защищена от автоматического подключения; её перенос требует отдельной проверки схемы и резервной копии.

Существующая приватная база и исходные материалы в рабочей облачной папке сохранены. Отсутствие этих файлов в GitHub — намеренное исключение данных, а не удаление. Команда резервирования: `python -m scripts.manage backup` в активной виртуальной среде. Для PostgreSQL предусмотрен SQLAlchemy URL с psycopg, перенос истории пока не реализован.
